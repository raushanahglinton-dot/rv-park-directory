How to add a new state

The entire directory lives in one file: data.js. Adding a state means adding park objects to the PARKS array. The site handles all filtering, sorting, and display automatically.

Step 1 — Open data.js

Find the file data.js in the root folder. Scroll to the bottom where you'll see the comment // ADD YOUR NEXT STATE HERE.

Step 2 — Copy the template

Each park is a JavaScript object. Copy this template and fill in the fields:

// One park entry { name: "Blue Ridge RV Park", city: "Blue Ridge", county: "Fannin", state: "Georgia", // spelled out, e.g. "Georgia" not "GA" region: "North GA", // your choice — shows in filter + card type: "Private", // see valid types below sites: 48, // number, must be under 100 hookup: "Full hookups, 30/50A", phone: "(706) 555-0100", // "" if unknown web: "blueridgervpark.com",// no https:// prefix; "" if none tags: ["Lake","Fishing","Blue Ridge Scenic Railway"] },

Step 3 — Valid values

type — must be exactly one of these four strings:

  • "Federal / NPS" — National Parks, National Forests (book at recreation.gov)
  • "State Park" — any state-managed campground
  • "Corps of Engineers" — US Army Corps lakes (also on recreation.gov)
  • "Private" — commercial or family-owned parks

hookup — free text, but include at least one of these keywords so the hookup filter works:

  • "Full hookups" — water, electric, and sewer
  • "Electric" and/or "water" — partial hookups
  • "No hookups" — dry camping only

web — omit https://. The site adds it automatically. Use "" if the park has no website — it will display "No website."

phone — standard US format preferred: "(555) 123-4567". Use "" if unknown.

tags — 2–5 short descriptive strings. Used by the search bar. Good examples: nearby landmarks, activities, special features, lake names.

Step 4 — Where to find data

For parks with no website, these sources are the most reliable for finding site counts and contact info:

  • Recreation.gov — all federal and Corps sites; site counts are listed on each campground page
  • AllStays Camp & RV app — covers 50,000+ campgrounds including tiny private parks; shows site counts
  • Campendium — campendium.com — user reviews often include site counts and hookup details
  • The Dyrt — thedyrt.com — good for private parks without websites; filter by state
  • RV Life Campground Reviews — campgrounds.rvlife.com — searchable, includes site count data
  • State park reservation systems — each state has its own; site maps show exact counts
  • Google Maps — "Questions & Answers" section on park listings often includes site counts from owners

Step 5 — Save and reload

Save data.js and refresh index.html in your browser. The new state will appear automatically in:

  • The state tabs at the top of the directory
  • The State dropdown in the sidebar filter
  • The hero stats (park count and state count update automatically)
  • The Region dropdown (regions auto-populate from your data)

Hosting on GitHub Pages (free .io domain)

To publish your site at a custom domain like smallrvparks.github.io:

  • Create a free GitHub account at github.com
  • Create a new repository named your-username.github.io
  • Upload all four files: index.html, style.css, app.js, data.js, plus the two helper pages
  • Go to Settings → Pages → set Source to "main" branch
  • Your site goes live at https://your-username.github.io within a minute

To add a custom .io domain (e.g. smallrvparks.io), register the domain at a registrar like Namecheap or Cloudflare, then point it to GitHub Pages using a CNAME record. GitHub's documentation at docs.github.com/pages walks through this in detail.

To update the directory with new parks, edit data.js and push to GitHub — the site updates immediately, no build step required.
